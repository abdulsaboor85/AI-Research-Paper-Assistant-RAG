AI Research Paper Assistant RAG - Commands

1. Create virtual environment

Windows:
python -m venv venv

Mac/Linux:
python3 -m venv venv


2. Activate virtual environment

Windows:
venv\Scripts\activate

Mac/Linux:
source venv/bin/activate


3. Install Python dependencies

python -m pip install -r requirements.txt


4. Create environment file

Create a file named .env in the project root.
Add your Gemini API key:

GEMINI_API_KEY=your_api_key_here


5. Run RAG answer debug

python src/rag_answer_debug.py "papers/your_paper.pdf" "your question"

Example:
python src/rag_answer_debug.py "papers/easy/cybersecurity_easy.pdf" "what should employees do"

Use --full-vectors if you want complete vectors instead of vector previews.


6. Run paper difficulty analysis

python src/analyze_pdf.py "papers/your_paper.pdf"

Example:
python src/analyze_pdf.py "papers/easy/cybersecurity_easy.pdf"


7. Run interactive Q&A pipeline

python pipeline/pipeline.py "papers/your_paper.pdf"

Example:
python pipeline/pipeline.py "papers/easy/cybersecurity_easy.pdf"

Then type questions in the terminal.
Type exit to stop.
