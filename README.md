# AI-Research-Paper-Assistant-RAG

## Project Structure

- `src/` - runnable Python entrypoints
- `pipeline/` - RAG pipeline modules
- `scripts/` - helper scripts used by the app
- `docs/` - setup and usage notes
- `papers/` - input research papers
- `reports/` - generated reports
- `assets/` - images and visual assets

## Common Commands

```bash
python src/rag_visualizer.py "papers/easy/cybersecurity_easy.pdf" "what should employees do"
python src/analyze_pdf.py "papers/easy/cybersecurity_easy.pdf"
python pipeline/pipeline.py "papers/easy/cybersecurity_easy.pdf"
```
